Chỉnh xong bấm Lưu & xuất file để tải thêm file live.json.

  1. Sửa đơn hàng, sản phẩm, kho, nhập hàng, mã giảm giá, livestream ở các mục bên trái.
  2. Bấm Lưu & xuất file (góc phải trên). Máy tải về store.json, live.json và admin-data.json. Nếu trình duyệt hỏi cho tải nhiều file, bấm Cho phép.
  3. Vào GitHub repo → Add file → Upload files → kéo cả 3 file vào → Commit changes.
  4. Chờ 1–2 phút, khách tải lại trang (Ctrl + F5) là thấy. Lần sau mở admin, dữ liệu tự nạp lại từ admin-data.json.

Lưu ý: thay đổi chưa xuất file chỉ nằm trong trình duyệt này. Kho web không tự trừ khi có đơn. Đăng nhập chỉ chặn người vào nhầm, không thay thế bảo mật thật, vì file admin và dữ liệu nằm công khai trên GitHub Pages.
